Your Recipe Companion

A local-first, mobile-first recipe book with bilingual ingredient support, beautiful recipe-card exports, JSON backup/restore and optional Google Drive sync.

What is Arusuvai?

Arusuvai is a standalone recipe book designed for everyday kitchen use. Recipes, favorites, recent recipes and the culinary dictionary are kept locally in the browser, while optional Google Drive sync provides an additional backup path.

Core features

📖 Complete recipe cardsRecipe identity, bilingual names, timing, servings, difficulty, toolkit, profile, ingredients, cooking phases, cheat sheet and notes.
♥ Favorites & recent recipesQuickly return to recipes you use most often or opened recently.
🔎 Multi-language searchSearch recipe names, Recipe No., local-language names, ingredients, aliases, cuisine and taste.
📚 Culinary DictionaryMaintain English/local-language terms, aliases and categories for cross-language ingredient discovery.
✏️ Recipe builderCreate, edit, duplicate and delete recipes with grouped ingredients and timed instructions.
🌗 Light & dark themesRecipe viewing and exports follow the active theme.
🖼 3× PNG exportThe complete recipe card is rasterised at three times the base export resolution.
🖨 PDF / printUse the browser print dialog to print or save the complete recipe card as PDF.
🍲 Background watermarkRecipe artwork can be used as a subtle background watermark; the option is enabled by default.
💾 JSON backup / restoreBackup settings, recipes, dictionary or all data, with optional favorites and recent recipes.
🔄 Merge / replaceImported Arusuvai backups are identified before matching data is merged or replaced.
☁️ Google DriveSynchronize selected JSON data with the user's own Google Drive.

Recipe export

PNG and PDF/print exports use the structured recipe-card layout. The recipe artwork watermark is optional and is checked by default.

Watermark ON  → theme base + low-opacity recipe artwork + recipe card
Watermark OFF → clean active-theme recipe card
PNG           → 3× raster rendering
PDF           → browser Print / Save as PDF
For dark-theme watermark exports, the base is intentionally dark so the background artwork does not overpower the recipe text.

Backup & restore

  • App Settings — app configuration and theme-related settings.
  • Recipes — recipe records, favorites and recent-recipe information.
  • Culinary Dictionary — dictionary entries and categories.
  • All Data — complete Arusuvai data in one JSON file.
  • Favorites and Recent Recipes can be included in backup files.
  • Import supports Merge or Replace for the matching backup type.

Recipe JSON backups do not carry the embedded recipe artwork payload. Built-in/default artwork is restored by the application. Keep any separately supplied custom artwork separately if required.

Google Drive sync

Google Drive is optional. The current implementation supports App Settings, Recipes, Culinary Dictionary and All Data.

  • Connect from Settings → Data Backup.
  • Choose the data types to sync.
  • If both local and Drive data exist, choose local, Drive or merge.
  • The implementation uses Google Identity Services and the Drive API with the drive.file scope.
  • A Google OAuth Web Client ID must be configured for the hosted deployment.

Privacy & legal

Core recipe data stays in browser storage on the device/browser where Arusuvai is used. When Google Drive is explicitly connected, selected backup data is sent to the user's own Drive through Google's APIs.
